# Генератор коммерческих предложений

Онлайн-инструмент для создания коммерческого предложения на собственном фирменном бланке.

## Как пользоваться

1. Откройте [генератор КП](https://viktoria129-dt.github.io/kp-generator/).
2. В разделе **«Бланк»** загрузите фирменный бланк в формате `.docx`.
3. Заполните исходящий номер, дату, город и заголовок документа.
4. При необходимости включите пункт **«Добавить название объекта»** и укажите его название.
5. Добавьте таблицу одним из способов:
   - загрузите файл Excel или CSV;
   - скопируйте ячейки из таблицы и вставьте их через кнопку **«Вставить из буфера»**.
6. Проверьте данные в предпросмотре. Каждую ячейку можно отредактировать прямо на странице.
7. Заполните условия доставки, должность и ФИО директора.
8. При необходимости загрузите изображение печати в формате PNG или JPEG.
9. Скачайте нужную версию документа:
   - **цветная версия** — цветной бланк без печати;
   - **чёрно-белая версия** — чёрно-белый бланк с цветной печатью, если она была загружена.

## Важно

- Встроенных бланков и печатей нет — пользователь загружает собственные файлы.
- Загружая печать и бланк, пользователь подтверждает право на их использование.
- Файлы обрабатываются только на устройстве пользователя и не отправляются на сервер.
- После обновления или закрытия страницы бланк и печать потребуется загрузить заново.
- Сайт не выполняет автоматическую проверку правильности реквизитов и содержимого документа.

## Поддерживаемые файлы

- Бланк: `.docx`
- Таблица: `.xlsx`, `.xls`, `.csv`
- Печать: `.png`, `.jpg`, `.jpeg`
